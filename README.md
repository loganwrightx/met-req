# Met-Req

This project, pronounced like `metric`, is intended to be an open-sourced, locally-hosted web application that allows users to build and maintain a requirements-based development suite. The distinguishing features of this program include:
- Natural self-pruning mechanisms powered by metric-tracking
- Maintaining a large nested database of requirements + tests + results + artifacts
- Version-control of each node in the database
- Linkages/relations between every node in the database
- And automatic test matrix generation/updates
